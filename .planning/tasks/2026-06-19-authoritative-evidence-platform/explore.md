# Explore - 2026-06-19-authoritative-evidence-platform

Date: 2026-06-19
Level: CRITICAL

## User Intent

建设疾病无关的本地医学研究执行平台。系统准确下载多维权威数据，记录出处并进行分维
标准化、可视化、确定性靶点筛选，以及文献、临床、市场和专利情报收集。机器只执行，
研究判断由人工完成。

## Existing Reality

- 当前 `target-research-platform` 已有若干 API 客户端和四阶段流程，但主要围绕肿瘤靶点。
- 2026-06-18 证据门禁任务开始修复单源成功、猜测候选和稿件污染问题。
- 旧架构草案仍包含 LLM 推理、自动评分和假设生成，与新边界冲突。
- 当前没有七维通用数据适配器准入、三层数据目录、四阶段签署和授权数据隔离模型。

## Main Contradiction

产品目标是可追溯研究执行，但历史实现和架构仍倾向于聚合摘要、自动排名和自动生成
结论。V2 必须把可信数据、确定性处理、人工审核和失败关闭放在功能数量之前。

## Constraints

- 本地/内网优先。
- 开放数据和用户授权数据并存。
- 七维组学采用后期整合。
- LLM 只做检索与翻译。
- V1 人类研究优先。
- 新来源必须经过白名单准入。
