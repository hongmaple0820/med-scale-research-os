# Spec - 2026-06-19-authoritative-evidence-platform

Date: 2026-06-19
Level: CRITICAL
Status: FROZEN
Ambiguity score: 10%

## Goal

将 MedSCALE Research OS 演进为疾病无关、本地优先、可验证的医学研究执行平台，完成真实
数据采集、七维标准化、证据矩阵、确定性筛选、四类情报和强制人工签署的完整闭环。

## Functional Scope

1. 权威数据源白名单和用户授权来源隔离。
2. 真实文件下载、稳定 ID、许可和哈希 manifest。
3. raw/normalized/analysis 三层数据模型。
4. 七维组学独立 QC、标准化和方法卡。
5. 跨维后期证据矩阵、冲突和缺失表达。
6. 版本化确定性规则和候选解释。
7. 文献、临床、监管、市场和专利证据包。
8. 四阶段不可绕过的人工审核。
9. 固定基准集和项目阳性对照。
10. 来源、schema、质量、许可和可复现性监控。
11. 版本化术语注册表、规范实体映射和人工消歧队列。
12. 原文语言分库、可基准验证的多路检索和逐声明 claim ledger。
13. 研究设计、风险偏倚、证据确定性和适用性分离。
14. 医学证据与商业事实物理隔离，所有外发内容单独审批。

## Out of Scope

- 自动推荐最终靶点。
- 自动生成临床、市场、专利法律或投资结论。
- 以 LLM 填补缺失数据或证据。
- V1 支持任意物种。
- 未经准入即可参与筛选的数据源。
- 首批同时实现所有数据库适配器。

## Acceptance Criteria

- [ ] 每个原始文件都有来源、许可、稳定 ID、获取时间和 SHA-256。
- [ ] 七维各有两个通过准入的权威来源；不足时流程阻断。
- [ ] 每个转换都有方法、公式、参数、软件版本和诊断图。
- [ ] 任意候选可追溯到具体原始记录。
- [ ] 入选、排除、冲突和缺失原因同时可见。
- [ ] 四个审核点不可绕过；上游变化撤销下游签署。
- [ ] 双重阳性对照失败时系统阻断。
- [ ] 文献、临床、市场和专利事实可定位原文。
- [ ] 授权数据不离开本地，也不进入公开交付物。
- [ ] LLM 关闭后核心流程仍可运行。
- [ ] 相同输入、版本和参数可重建一致产物清单。
- [ ] 系统不自动输出最终靶点推荐。
- [ ] 每个规范实体映射可追溯到词表版本、候选和人工决定。
- [ ] 每条正式陈述都有原文 locator；无定位时阻断。
- [ ] 系统不把自定义分数表述为 GRADE，也不使用 IF/引用量自动提升证据确定性。
- [ ] 检索权重和 Top-K 只有通过冻结人工基准后才能进入生产配置。
