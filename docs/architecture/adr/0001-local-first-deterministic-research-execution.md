# ADR-0001：采用本地优先的确定性研究执行架构

## Status

Accepted

## Context

平台需要处理公开数据、用户授权商业数据、密钥和可能敏感的研究产物。用户要求机器只执行
可验证命令，不能依靠模型推理形成研究结论。

## Decision

基础平台采用本地/内网模块化单体。所有关键采集、转换、统计和筛选均由版本化确定性程序
执行。LLM 不是运行时依赖，仅能在受限通道辅助检索和翻译。

## Consequences

### Positive

- 授权数据和密钥不离开用户环境。
- 无 LLM 时仍可完成研究流程。
- 调试、部署和审计边界清晰。

### Negative

- 用户需承担本地存储、计算和备份。
- 团队协作和远程访问需要后续内网能力。

## Alternatives Considered

- 公有云 SaaS：授权和数据边界风险过高。
- LLM 驱动 Agent 工作流：不可重复且容易越过人工判断边界。
- 微服务：V1 运维成本过高。
