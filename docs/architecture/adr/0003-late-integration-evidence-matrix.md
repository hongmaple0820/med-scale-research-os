# ADR-0003：七维组学采用后期证据矩阵整合

## Status

Accepted

## Context

转录、变异、蛋白、功能依赖、表观、单细胞和空间数据具有不同量纲、采样单位、缺失机制
和质量模型。将其压成一个分数会制造伪精确性。

## Decision

各维度独立质控和标准化。跨维层只汇总方向、效应量、置信度、来源质量、冲突、缺失和
适用范围。确定性规则可筛选候选，但不得生成不可解释的黑箱总分。

## Consequences

### Positive

- 保留每个维度的真实含义。
- 冲突和缺失不会被平均值掩盖。
- 候选入选和排除原因可解释。

### Negative

- 人工阅读成本高于单一排名。
- 可视化和规则配置更复杂。

## Alternatives Considered

- 统一综合评分：信息损失和权重主观性过高。
- 完全人工浏览：难以规模化、难以复现。
- 多模型机器学习排名：需要训练标签且不符合确定性执行边界。
