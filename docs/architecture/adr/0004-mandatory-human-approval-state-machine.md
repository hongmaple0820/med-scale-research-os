# ADR-0004：采用不可绕过的四阶段人工审批状态机

## Status

Accepted

## Context

医学数据来源、标准化方法、筛选规则和情报解释均可能产生重大偏差。用户要求每一步结果
经人工审核后才能继续。

## Decision

采集、标准化、靶点筛选和情报分析均以 `REVIEW_REQUIRED` 结束。只有带输入/输出哈希、
规则版本、审核人和签名的 `APPROVED` 记录才能解锁下一阶段。上游产物变化自动撤销下游
批准。

## Consequences

### Positive

- 人工责任和决策边界明确。
- 防止无效数据自动扩散到下游。
- 支持完整审计和问题定位。

### Negative

- 吞吐量受审核速度限制。
- 需要角色、签名、通知和修订体验。

## Alternatives Considered

- 只在最终报告审核：错误发现过晚。
- 可选审核：无法保证强制边界。
- 自动放行低风险步骤：风险分类本身仍需可信依据。
