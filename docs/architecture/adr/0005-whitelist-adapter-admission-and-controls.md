# ADR-0005：数据源采用白名单准入与双重阳性对照

## Status

Accepted

## Context

外部数据库会发生 schema、许可、接口和数据版本变化。自由添加来源会破坏可验证性。

## Decision

数据源只有在完成许可审查、稳定 ID 验证、下载/解析测试、schema 漂移测试、固定基准集
和版本化 manifest 后才能进入白名单。每个项目还必须配置与研究场景相关的阳性对照。

## Consequences

### Positive

- 数据源变化能在进入正式分析前被发现。
- 系统级和项目级问题可以区分。
- 新来源的质量责任明确。

### Negative

- 新增适配器速度较慢。
- 需要维护基准数据和容差版本。

## Alternatives Considered

- 项目自由添加来源：灵活但不可治理。
- 只使用固定系统基准：无法发现疾病/项目特异错误。
- 只使用项目对照：无法稳定监控适配器自身。
