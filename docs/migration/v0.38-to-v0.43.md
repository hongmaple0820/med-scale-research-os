# 迁移：v0.38 → v0.43 / Migration: v0.38 → v0.43

> 权威完整指南见 [`docs/guides/MIGRATION.md`](../guides/MIGRATION.md)。本文聚焦 0.38–0.43 区间的关键变更。

## 概览 / Overview

| 版本 | 主题 |
|---|---|
| 0.38.0 | 受管依赖 bootstrap 包 (ui/external-cli/memory/knowledge)、外部优先记忆路由 |
| 0.39.0 | `scale prompt optimize`、`scale gates status --json`、`scale score task` |
| 0.40.x | AI OS Runtime、MapleOS HTTP bridge、gbrain 默认记忆提供方、setup/upgrade 向导 |
| 0.41.0 | 8 方向综合优化、66+ CLI 命令、16 治理门禁 (G9-G15) |
| 0.42.0 | **三引擎架构 (Shield / Orchestrator / Cortex)**、门禁扩展 G0-G22 |
| 0.43.0 | 增强门禁 G16-G22、治理锁同步、`scale cortex verify`、迁移文档 |

## 破坏性变更 / Breaking changes

### CLI 命令重构 (0.42)

扁平命名空间 → 嵌套子命令树。受影响的脚本：

| 旧 | 新 |
|---|---|
| `scale context inject` | `scale cortex inject` |
| `scale doctor` | `scale verify` |

新命令组：`scale shield`、`scale orch`、`scale cortex`、`scale upgrade`。

### 门禁系统扩展 (0.42 → 0.43)

- 核心门禁 G0-G8：行为不变。
- 元治理门禁 G9-G15：默认关闭。
- 增强门禁 G16-G22：新增（提交纪律、文档卫生、运行时证据、代码评审、供应链、上下文预算、会话健康）。

`make gate-workflow` / `make gate-quality` 已更新；`.scale/workspace.json` 自定义门禁配置保持兼容。

### 源码目录重组 (0.42)

`src/shield/`、`src/orchestrator/`、`src/cortex/`。内部导入路径变更——若曾从 `src/core/` 或 `src/governance/` 导入需更新到引擎专用路径。

### Hook 退出码协议 (0.42)

`.claude/hooks/` 切换为 exit 0=allow / exit 2=block。旧版 exit 0/1 钩子仍可运行，但应针对新 Shield 协议测试。计划在 0.44.0 移除旧格式。

### 治理锁 (0.43)

`.scale/governance.lock.json` 的 `scaleVersion` 必须与已安装包版本一致。重算并对齐：

```bash
scale upgrade apply --dir . --confirm
```

## 弃用时间线 / Deprecation timeline

| 弃用项 | 移除版本 | 替代 |
|---|---|---|
| `scale context inject` (独立) | 0.43.0 | `scale cortex inject` |
| `scale doctor` (独立) | 0.43.0 | `scale verify` |
| 旧 hook 格式 (exit 0/1) | 0.44.0 | Shield 退出协议 (0/2) |
| `.scale/state/` 扁平产物 | 0.44.0 | 引擎专用状态目录 |

## 验证 / Verify

```bash
scale upgrade check --dir .
scale upgrade diff --dir .
scale verify --dir .
```
